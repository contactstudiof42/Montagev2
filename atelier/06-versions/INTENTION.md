# Pièce 06 « Versions » — intention (écrite avant de créer)

Session 5, 2026-10-10. BACKLOG 26, principe d'Errol Morris (*The Thin Blue Line*, `culture/errol-morris-thin-blue-line.md`) : rejouer la même scène avec des variations pour montrer **des versions, pas un fait**.

## Le sujet
Une tasse posée au bord d'une table, dans une pièce vide éclairée par une fenêtre. Elle tombe. Trois fois. Même cadre, même durée, même chute. Un seul détail change à chaque version :
1. **Seule** : rien ne se passe, puis elle tombe. (Accident ? On ne sait pas.)
2. **La table tremble** : une secousse brève avant la chute. (Quelqu'un a cogné la table ? Un camion dans la rue ?)
3. **Une ombre passe** sur le mur et la table avant la chute. (Quelqu'un était là.)

## Ce que je veux faire ressentir
Le doute qui monte. La première version paraît une évidence ; la deuxième la rend fragile ; la troisième accuse quelqu'un qu'on ne voit jamais. Le spectateur doit sortir en se demandant **laquelle est la vraie**, et comprendre que c'est le montage qui la lui a fait croire.

## Choix a priori
- **Cadre identique** pour les trois versions (Morris : même cadre pour comparer) ; plan large fixe à hauteur de table.
- **Un insert d'objet** identique avant chaque version : la tasse au bord, en gros plan, immobile (la question).
- **Une musique en boucle** (arpège répétitif, type Glass) qui ne change pas : la boucle dit « on recommence ». Elle s'arrête net sur la dernière chute, sans le son de la casse : le silence est le verdict qu'on ne donne pas.
- Un carton minimal « 1 », « 2 », « 3 » ? Non a priori : la répétition suffit, les numéros feraient « démonstration ». À tester.
- Format 16:9, ~12 s, 480×270 pour aller vite.

## Critères de réussite
1. On reconnaît immédiatement que c'est la **même** scène (cadre et timing identiques, mesurés).
2. Chaque détail changé est **lisible** sur la planche (secousse visible, ombre visible) sans être appuyé.
3. La 3e version modifie le sens des deux premières (on relit la 1re : y avait-il quelqu'un ?).
4. Pas de surexplication : aucun texte, aucun personnage visible.
