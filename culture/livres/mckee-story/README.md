# *Story*, Robert McKee (1997) — ressource consultable

Robert McKee, *Story: Substance, Structure, Style, and the Principles of Screenwriting*, ReganBooks / HarperCollins, 1997, 466 p. (édition anglaise originale). Livre de référence de l'écriture de scénario de long métrage : ce qu'est une histoire, comment elle se construit de l'événement au film entier, et comment l'écrire.

_Fiches écrites le 2026-10-23, à la demande de Diego, qui a fourni le PDF. Chaque chapitre a été lu en entier (six lecteurs en parallèle, même gabarit), puis relu par moi, avec des vérifications ponctuelles contre le texte. Tout le contenu des fiches est [SOURCÉ] (page du livre entre parenthèses), sauf les sections « Pour le studio », qui sont [THÉORIQUE] (ma transposition aux formats du studio, jamais éprouvée sur un projet). Le skill qui s'en sert : `.claude/skills/montage-ecriture-scenario/`._

## Comment consulter
1. **Par question** : le tableau ci-dessous envoie à la bonne fiche.
2. **Par concept** : le glossaire, en bas, donne le terme de McKee, sa traduction retenue, la fiche et la page.
3. **Pour le texte exact** : le texte complet du livre, reconnu par OCR, est sur le Mac, hors Git (droit d'auteur) : `videos/livres/mckee-story/chapitres/NN-*.txt`, un fichier par chapitre, chaque page marquée `=== p. N du livre ===`. Chercher avec `grep -n -i "mot" videos/livres/mckee-story/chapitres/*.txt`. Le scan d'origine : `videos/livres/mckee-story/story.pdf`.

Les fiches sont courtes (environ 10 % du chapitre) : beaucoup d'exemples de films ont été coupés. Pour un exemple développé ou une nuance, retourner au texte (point 3).

## Limites de la ressource
- **Pages absentes du scan** : la bibliographie, la filmographie et le début de l'index (p. 422–458) ; quelques pages de titre de parties. Le texte des 19 chapitres est complet.
- **OCR** : une vingtaine de lignes illisibles, signalées par les lecteurs (surtout p. 69, 140–148, 213–231, 292–332, 349–397) ; le sens se reconstitue par le contexte, mais une citation exacte se vérifie dans `story.pdf`. Les schémas (triangle p. 45, courbes p. 123, actes p. 218–221) sont mal rendus par l'OCR ; le triangle a été relu sur l'image.
- **Le livre parle du long métrage de fiction hollywoodien de 1997.** Les chiffres (40 à 60 scènes, incident déclencheur dans le premier quart, trois actes) ne se transposent pas tels quels à une pub ou à un Short ; McKee le dit lui-même pour les œuvres de 5 à 20 min (un acte, p. 217).
- **McKee dans le texte, pas les critiques de McKee** : ces fiches ne disent pas ce que d'autres reprochent au livre (formatage du cinéma hollywoodien, etc.).
