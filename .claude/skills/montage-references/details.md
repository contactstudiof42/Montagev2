# montage-references — sources, exemples, mises à l'épreuve

## A. Le temps comme argument
1. Glazer, Guinness *Surfer* : si le message est « attendre », faire attendre. Exemples : cuisson, artisanat → plans longs.
2. Menke : la durée d'une tension est proportionnelle au risque ; la résolution est **beaucoup** plus courte que l'attente.
3. Un seul ralenti bien placé vaut mieux que du ralenti partout.
4. Aviron de *The Social Network* : Baxter et Wall ; la musique accélère **déjà**.
6. *Aftersun* (Wells / McClendon, `culture/aftersun-wells-mcclendon.md`) : fragments **anodins**, archive incomplète ; textures par régime : 35 mm, MiniDV, espace mental (remplacent le carton « il y a longtemps ») ; un plan tenu un peu trop longtemps se charge après coup de ce qui suit ; quand un montage ne touche plus, revenir aux deux ou trois moments qui émeuvent encore et reconstruire autour. Corrige l'atelier 05 : le souvenir demande un changement de texture **et** une structure.
7. *Les Revenants* (Gobert, `culture/les-revenants-gobert.md`) : pas d'effets, cadres posés, durées longues, musique retenue (Mogwai composée sur les scripts, avant le tournage) ; le spectateur ne sait plus quand avoir peur. Atelier 12 (session 9) : 3 plans fixes, une seconde tasse apparaît pendant qu'on regardait la fenêtre ; l'anomalie tombe là où le regard est déjà (cécité au changement à travers la coupe, mesurée par saillance, `montage-grammaire`) ; plan de retour plus long que le plan de départ.
8. Haneke (`culture/michael-haneke-plan-tenu.md`, session 25, sous-agent) : le son du hors-champ remplace le visage ; l'élément décisif petit et décentré, sans insert (fin de *Caché*). Pièce 34 : les voix filtrées portent la scène, mais la buée était invisible en v3 ; Haneke compte sur la salle, pas sur un téléphone. Festival : tenir ; web : amener le détail à la taille de lecture.

## B. Image et musique
- Bass : peu d'éléments, chacun sur un temps ; clarté, élégance. Gondry : les accents tombent sur des événements internes à l'image, pas sur les coupes ; le public prend plaisir à vérifier la règle. Cooper : caler l'image sur les accidents du son, pas ses temps forts ; rythme irrégulier. Contrepoint : Ellington chez Bass.
- Saturation (générique d'*Enter the Void*) : cartons de quelques images ; paramètres forts = police, teinte, échelle ; montage verrouillé sur la musique **avant** le design (Kan a jeté ~40 % de ses cartons) ; sommet = les noms des acteurs ; un sas vers l'état du film, on ne lit plus. Photosensibilité : `montage-kinetic-editing` § 5.

## C. Réduire à une idée
9. Bass : une forme que toute l'animation révèle ou transforme.
10. Wright : 5 à 8 plans de **6 à 12 images**.
11. Clair, *True Detective* : le corps sert de cadre au lieu. Portrait de marque : le visage d'un artisan comme fenêtre sur son atelier.
12. Glazer : le noir et blanc, rien de touristique.
13. *Game of Thrones* (Elastic / Angus Wall, `culture/elastic-game-of-thrones-generique.md`) : la carte est née parce que le public se perdait ; un générique qui informe et varie donne une raison de le regarder (habillage de série corporate : dire quelque chose de neuf à chaque fois). ManvsMachine (`culture/manvsmachine-studio.md`) : une matière ou un geste par bénéfice produit, un élément qui revient, des règles qui se déclinent (palette, kit de pièces) → toute pub déclinée 16:9 / 9:16 / 6 s. Habillages longs (`culture/generiques-series-documentaires.md`, session 8 : *Chef's Table*, *Making a Murderer*, *Faites entrer l'accusé*) : attaque musicale singulière dès la 1re seconde ; une musique à motif court supporte la répétition, une musique à effet (montée, drop) s'use (test : 10 écoutes d'affilée) ; l'identité en **rituels brefs** qui survivent aux changements d'équipe ; test : échangeable avec un autre programme = mode, pas identité.
14. Rangs (`culture/affiches-line-up-festivals.md`, session 16) : 3 rangs + un carton ; alphabétique dans le rang ; la durée et la place dans le temps remplacent la taille et la place sur la feuille ; égaliser le temps de lecture (nom long = plus d'images). Usages : programmation, générique, palmarès, liste de clients. Hiérarchie (Glastonbury, Lollapalooza) : une taille ou une durée unique est un manifeste d'égalité, pas un choix neutre ; sans manifeste, un papier peint.
15. John Lewis (`culture/pub-emotionnelle-noel-john-lewis.md`, session 10) : la fable évite la pitié ; le geste doit atteindre l'autre (reproche fait à *Man on the Moon*) ; la reprise lente d'un tube est devenue un cliché de catégorie. Pièce 16 : une fable empruntée (petite planète + silhouette = *Le Petit Prince*) importe le sens d'une autre œuvre ; objet propre : le fil du téléphone qui descend jusqu'à la Terre ; fil noir sur fond noir = rien ; v4 (session 11) : un réseau de petits mondes reliés à la Terre, fils détendus (« tenu ») bat la planète seule (« perdu »).

## D. Matière et texture
16. Cooper : typo gravée, papier scanné, pellicule. Défauts comme matière : Clair (ralenti extrême), *The Hardest Part* (la dérive de l'IA comme sujet).
17. Elastic : bois, métal, engrenages, caméra « motion control » seulement. ManvsMachine : garder poids et inertie, ne casser qu'une règle à la fois.
18. Buck (`culture/buck-studio.md`) : planche de style d'abord, puis dessin, 3D et stop-motion selon le plan ; transformations au rythme de la parole.
19. *Catch Me If You Can* (`culture/kuntzel-deygas-catch-me-if-you-can.md`) : tampons encreurs pour un faussaire, défauts gardés ; silhouette sans visage pour un homme aux identités changeantes ; chaque aplat dit « ailleurs, plus tard » sans carton ; reprendre la logique de Bass (un signe, peu de couleurs, typo dans le décor). Pôle opposé de Noé / Kan : lisible, narratif, continu.
20. *Scott Pilgrim* (Shynola / Edgar Wright, `culture/scott-pilgrim-generique-et-montage.md`, session 8) : typo, couleur, mouvement changent avec la scène ; événement réel = un flash, un geste, un transitoire ; une seule source esthétique pour tous les effets (jeu vidéo low-fi, cadence comprise).
21. Marey (`culture/chronophotographie-marey-muybridge.md`, session 16) : fond noir + sujet réduit à des lignes claires = les poses s'additionnent en trajectoire ; Muybridge : images séparées sur repère quadrillé = phases comparables. Pièce 20 : l'éclair = obturateur ; l'écho des corps révélés est une chronophotographie, pas un effet.
22. Braier (`culture/natasha-braier-lumiere-de-nuit.md`, session 12) : ni jaune ni orange ; la source doit toucher le visage et colorer l'ombre, sinon elle fait « clip ».

## E. Raccords et structure
23. Wright : jamais un fondu par défaut.
24. *The Social Network* : raccords question / réponse entre présent et passé ; documentaire corporate : l'interview pilote les allers-retours vers l'archive. Menke : blocs début / milieu / fin pour permuter et chapitrer.
25. Murai : la coupe prévient et amortit ; le premier plan donne le plaisir, l'arrière-plan le sens ; l'inverse exact du kinetic. Åkerlund (« Smack My Bitch Up », `culture/jonas-akerlund-smack-my-bitch-up.md`) : la coupe rapide imite une perception (ivresse, trou de mémoire) ; garder pour la fin l'information qui oblige à relire. Gavras (« Stress », « Born Free », `culture/romain-gavras-stress-born-free.md`) : caméra présente dans le monde, ni ralenti ni coupe sur le beat ; sans point de vue lisible, pris au premier degré (accusations de stigmatisation) ; indices : décalage, mise en abyme, caméra retournée contre celui qui regarde.
26. Varda (`culture/agnes-varda-les-glaneurs.md`) : texte écrit **après** chaque passe de montage pour relier, jamais pour illustrer ; garder l'accident qui rime (le cache qui danse sur le jazz) ; rimes d'objets. Marker (`culture/chris-marker-sans-soleil.md`) : « il m'écrivait » libère les sauts ; énoncer à l'écran son problème de montage (les enfants suivis de noir) ; traiter visiblement l'archive pour qu'elle ne passe pas pour une preuve ; spirale = 3-4 lieux ou motifs, chaque retour change le sens du précédent. Morris (`culture/errol-morris-thin-blue-line.md`) : des versions, pas un fait ; l'insert d'objet au ralenti comme question (le milkshake), réservé aux objets qui portent l'enjeu ; cadre identique pour tous les témoins quand il faut comparer ; musique en boucle pour un récit en boucle (Glass).
27. Jonze (`culture/spike-jonze-weapon-of-choice-welcome-home.md`) : la source musicale dans l'image fait de la musique un événement ; effet physique d'abord, numérique en complément ; lieu banal + transformation = merveilleux.
28. Bande-annonce (`culture/bande-annonce-montage.md`, session 9 : teaser d'*Alien* 1979, Mark Woollen, le « braaam » d'*Inception*) : une seule question laissée ouverte ; 50 s de faux Facebook avant le visage ; 3-4 paliers, chaque carton relance ; une phrase coupée en cartons sur les temps forts, lisible sans le son. Garde-fou : braaam et reprise lente d'un tube seulement si leur sens tient au sujet (« Creep » par un chœur d'enfants = solitude d'un film sur la connexion). → Pub 30 s, teaser réseaux.
29. Dougal Wilson / Kim Gehrig (`culture/dougal-wilson-kim-gehrig-pub.md`, confiance faible-moyenne) : test = relire la planche après la chute ; le cliché du genre comme leurre ; quand le sujet est le corps ordinaire, le casting est la direction artistique.

## F. Goûts de l'utilisateur
30. Ziak : seconde horloge = éclairs à 15 images contre un beat à 0,418 s ; l'effet = la lumière du tir, pas le tir ; « Même pas un grincement » = sans effort visible, sans transitions, sans calage voyant. Atelier 03 : densité par section contre montage calé au temps ; l'hybride l'emporte pour la pub et les réseaux.
31. Clips rap (`culture/clips-rap-francais-pnl-et-autres.md`, session 6 ; `culture/clips-drill-rap-fr-proches-ziak.md`, session 8 ; `culture/freeze-corleone-clips.md`, session 9) : un lieu ou concept (la tour Eiffel prise par PNL, l'usine sans visage de Ziak), un personnage seul dans un cadre immense ou aucun visage ; **épouser le tempo** (PNL, mélancolie) **ou le contredire** (Ziak, menace), selon l'émotion. Anonymat (Bleu Désert, Marius Gonzalez / Charles Nardin ; Gazo en contrepoint) : caméra thermique, vue subjective, corps-machine ; surveillance = 4:3, interface sobre, une couleur, rouge des cadres de ciblage ; « Vrai/Faux » : médiane de luminance 29/255, 51 % sous 30 contre 88 % pour « Grincement », saturation nulle (rejoint la pièce 08 : le support dit plus que l'étalonnage). Freeze : mystère dans le texte, clip sobre (noir et blanc, lieu unique chargé, personnage animé reconnaissable par un trait) ; un texte dense appelle une image simple, et inversement.
32. Pièce 29 « Deux horloges » (session 24) : ellipse dans la coupe = temps presque arrêté dans le plan ; un tic posé **sur** les retours devient une cause (à chaque tic, une perte), le rompre au dernier retour fait entendre l'absence.
34. EGO (`culture/ego-chaine-youtube.md`, session 17) : exemples d'objets (trombone, pion, silhouette minuscule devant l'immense) ; on fait sentir le problème, on nomme le concept ensuite ; couleurs mesurées sur 7 miniatures (blanc clinique, champ saturé unique, noir à lumière froide) ; le titre porte la phrase ; forme détournée = le faux tuto pour un sujet grave ; artisanat = métiers crédités, making of, refus affiché de l'IA générative. Même sound designer que Ziak (Émilien Bernaux) [SOURCÉ] ; points communs avec Interstellar (vertige d'échelle) et Joker (palette réduite) : hypothèses. Pièce 22 (session 18) : v1 la chaise sort du cadre, le vertige devient un motif ; v2 la chaise seule devant le front du champ = l'image du film ; silence de 4-5 s pendant le recul.
- Atelier 01 : « la forme du temps est l'argument » (rétention plus longue que confortable) et « un signe » (le mot qui retient son souffle) ont produit la v3.

## G. YouTube et internet (session 17 ; fait foi : `montage-youtube`)
Fiches : MrBeast (`culture/youtube-mrbeast-retention.md` : titre + image clé écrits avant le tournage ; 2024 : 38 → 23 coupes/min, un plan long est juste s'il fait quelque chose) ; face caméra FR (`youtube-fr-divertissement.md` : jump cut assumé, punch-in et bruitage remplacent la seconde caméra, le punch-in **réservé aux chutes**, jamais alterné ni comme cache-coupe, voir `montage-youtube` § 5) ; Every Frame a Painting (`video-essay-every-frame-a-painting-nerdwriter.md` : comparer plutôt qu'expliquer) ; Vox, Johnny Harris (`youtube-doc-explicatif-vox-johnny-harris.md` : une matière unique, la donnée matérialisée, le zoom continu comme plan d'établissement) ; Kurzgesagt (`kurzgesagt-motion-design.md` : voix définitive avant l'animation, l'image change quand l'idée change, mouvement de repos sous le seuil de l'événement) ; habillage (`motion-design-youtube-explicatif-et-habillage.md` : un template est déjà un cliché) ; vlog (`vlog-casey-neistat-et-heritiers.md` : l'authenticité est un effet de montage, le plan vide où le sujet entre, timelapse et drone comme ponctuation) ; internet (`cultures-edit-internet-ytp-vine-brainrot.md` : une contrainte forte crée un langage, deux images à l'écran doivent avoir un rapport ; une 6 s = installation / rupture / retour, pas un 30 s raccourci) ; live sessions (`youtube-musique-live-sessions.md`, COLORS, Tiny Desk, Blogothèque, KEXP, Audiotree, Mouv' : l'absence de montage prouve la performance ; une prise audio continue, l'image se monte dessus ; couper vers ce qu'on entend, visages et mains d'abord ; l'accident gardé prouve la vérité ; série de portraits corporate : un fond, un plan, une règle) ; gaming et podcasts (`youtube-gaming-et-twitch.md`, `podcasts-video-et-clips-verticaux.md` : chaque extrait doit tenir seul) ; dormir (`culture/asmr-slow-tv-videos-pour-dormir.md`, session 21 : NRK *Hurtigruten* non resserré, Bob Ross sans coupe, Lofi Girl ; chaque coupe réclame de l'attention ; une direction lente portée par le contenu, sans climax ; Poerio et al. 2018 : voix douce 74 %, chuchotement 70 % des déclencheurs cités ; l'écran n'est jamais noir, archives dans les tunnels).

## Tensions : précisions
- Kinetic pour l'énergie et la rétention sur les réseaux ; Ziak pour la gravité et la menace (clip, film de marque).
- Monter le choc = impact, flash, shake : fait plaisir et confirme ; le laisser arriver dérange et accuse.
- Couper toutes les 1,5 s = retention editing 2019-2023 ; respirer = MrBeast 2024, vlog, essai ; le téléviseur représente ~45 % du visionnage YouTube.
- Public captif = TV, cinéma, préroll non zappable.
