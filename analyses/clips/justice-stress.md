## Choix par domaine
- **Rythme** : peu de coupes, mais placées sur les accents de l'arrangement ; entre elles, la caméra portée fait le rythme (filés, coups, courses). La violence arrive dans le plan, pas dans la coupe.
- **Cadre** : caméra diégétique (on la frappe, on la menace, on la fait tomber) ; le logo de Justice (la croix) brodé sur les blousons est le seul signe de marque, porté par les personnages.
- **Couleur** : image froide, grise, désaturée, comme un reportage d'hiver ; le seul chaud est le feu de la voiture à la fin.
- **Son** : un mur de musique ; le silence n'existe que deux fois, à deux moments-clés (avant la bagarre du métro, après la chute de la caméra).

## Confirme, contredit, complète
- **Corrige** ma fiche de phase 1 sur un point de méthode : j'avais déduit « pas de calage » de l'esthétique du reportage. Mesuré, le monteur **cale bien ses rares coupes sur les grands accents** : le réalisme est dans le plan, la musicalité dans la coupe.
- **Complète** `montage-rythme` (« micro ou macro ») d'un troisième cas : **sur les accents, pas sur les temps**. Ziak suit la basse (macro), le kinetic suit les temps (micro), Stress suit les grands coups de l'arrangement.
- **Confirme** « le silence juste avant le coup » (Whiplash) : 0,6 s de silence puis la bagarre du métro.
- **Confirme** « après le plus fort, le vide » (Joker, Mad Max) : la caméra au sol, puis 4 s de silence total sur le noir.
- **Confirme** la règle de `montage-regard` sur la cohérence : tous les leviers servent le reportage (caméra portée, couleur grise, aucun effet), sauf la musique, qui reste le seul signe de clip. C'est le contrepoint voulu.

## Principes transférables
1. **Réel dans le plan, musique dans la coupe** : filmer comme un document, mais poser les rares coupes sur les grands accents de la musique.
2. **Le silence comme coup** : couper la musique 0,6 s avant l'acte le plus violent ; couper la musique net à la fin plutôt que la fondre.
3. **La caméra comme personnage** : si elle est dans le monde, on peut la frapper ; sa chute fait la fin.
4. **Le signe de marque porté par le décor** (le logo sur les blousons) plutôt qu'incrusté.

Pour Studio F42 : le principe 1 est la version « retenue » du montage sur musique, utile pour un film de marque ou un brand content qui veut paraître vrai. [DÉDUIT]
